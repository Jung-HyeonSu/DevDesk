# DevDesk

DevDesk는 브라우저에서 바로 사용할 수 있는 다국어 개발자 도구 모음입니다.

**사이트:** [https://devdesk-7e7.pages.dev/](https://devdesk-7e7.pages.dev/)

[한국어](README.ko.md) · [English](README.md) · [日本語](README.ja.md) · [简体中文](README.zh-CN.md)

## 주요 기능

- **개발자 도구 12종:**
  - JSON 포맷팅, 압축, 유효성 검사
  - SQL 포맷팅
  - JWT 헤더와 페이로드 디코딩 (서명 검증은 하지 않습니다)
  - Linux cron 표현식 생성
  - 텍스트 비교 및 diff 확인
  - Base64 인코딩 및 디코딩
  - URL 컴포넌트 인코딩 및 디코딩
  - Unix 타임스탬프 변환
  - UUID v4 생성
  - SHA-2 해시 생성
  - 중단 가능한 Web Worker에서 정규식 테스트
  - YAML과 JSON 간 변환
- 한국어, 영어, 일본어, 중국어 간체로 화면과 도구 페이지, 가이드를 제공합니다.
- 도구 검색, 즐겨찾기, 최근 사용 목록을 지원합니다.
- 라이트, 다크, 시스템 테마를 선택할 수 있습니다.
- 데스크톱과 모바일 화면에 맞는 반응형 인터페이스를 제공합니다.
- 호환되는 도구 사이에서 URL에 값을 넣지 않고 입력을 전달할 수 있습니다.

## 개인정보 보호

도구 입력은 브라우저에서 처리하며 도구를 연 동안 페이지 메모리에 유지됩니다. 계정 시스템이나 애플리케이션 서버는 없습니다. 브라우저 저장소에는 테마, 즐겨찾기, 최근 도구 같은 환경설정만 저장합니다.
