# DevDesk

DevDesk is a multilingual collection of practical developer tools that run in your browser.

**Website:** [https://devdesk-7e7.pages.dev/](https://devdesk-7e7.pages.dev/)

[한국어](README.ko.md) · [English](README.md) · [日本語](README.ja.md) · [简体中文](README.zh-CN.md)

## Features

- **12 developer tools:**
  - Format, minify, and validate JSON
  - Format SQL
  - Decode JWT headers and payloads (signature verification is not performed)
  - Generate Linux cron expressions
  - Compare text with a diff tool
  - Encode and decode Base64
  - Encode and decode URL components
  - Convert Unix timestamps
  - Generate UUID v4 values
  - Generate SHA-2 hashes
  - Test regular expressions in a stoppable Web Worker
  - Convert between YAML and JSON
- Browse the interface, tool pages, and guides in Korean, English, Japanese, or Simplified Chinese.
- Search the tool catalog, save favorites, and revisit recently used tools.
- Choose a light, dark, or system-matched theme.
- Use a responsive interface on desktop and mobile screens.
- Pass values between compatible tools without putting them in a URL.

## Privacy

Tool inputs are processed in the browser and stay in page memory while a tool is open. DevDesk has no account system or application server. Browser storage is used only for preferences such as theme, favorites, and recent tools.
