# DevDesk

DevDesk 是一组可直接在浏览器中使用的多语言开发者工具。

**网站：** [https://devdesk-7e7.pages.dev/](https://devdesk-7e7.pages.dev/)

[한국어](README.ko.md) · [English](README.md) · [日本語](README.ja.md) · [简体中文](README.zh-CN.md)

## 主要功能

- **12 种开发者工具：**
  - 格式化、压缩和校验 JSON
  - 格式化 SQL
  - 解码 JWT 标头和载荷（不验证签名）
  - 生成 Linux cron 表达式
  - 比较文本并查看差异
  - 编码和解码 Base64
  - 编码和解码 URL 组件
  - 转换 Unix 时间戳
  - 生成 UUID v4
  - 生成 SHA-2 哈希
  - 在可停止的 Web Worker 中测试正则表达式
  - 在 YAML 和 JSON 之间互相转换
- 提供韩语、英语、日语和简体中文界面、工具页面及使用指南。
- 支持搜索工具、收藏工具和查看最近使用的工具。
- 可选择浅色、深色或跟随系统设置的主题。
- 适配桌面和移动设备的响应式界面。
- 在兼容工具之间传递输入内容，且不会将内容放入 URL。

## 隐私

工具输入在浏览器中处理，工具打开期间仅保留在页面内存中。DevDesk 不设账户系统或应用服务器。浏览器存储仅用于保存主题、收藏和最近使用的工具等偏好设置。
