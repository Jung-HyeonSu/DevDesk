# DevDesk

DevDesk は、ブラウザーですぐに使える多言語対応の開発者向けツール集です。

**サイト:** [https://devdesk-7e7.pages.dev/](https://devdesk-7e7.pages.dev/)

[한국어](README.ko.md) · [English](README.md) · [日本語](README.ja.md) · [简体中文](README.zh-CN.md)

## 主な機能

- **12 種類の開発者向けツール:**
  - JSON の整形、圧縮、検証
  - SQL の整形
  - JWT ヘッダーとペイロードのデコード（署名の検証は行いません）
  - Linux cron 式の生成
  - テキストの比較と差分表示
  - Base64 のエンコードとデコード
  - URL コンポーネントのエンコードとデコード
  - Unix タイムスタンプの変換
  - UUID v4 の生成
  - SHA-2 ハッシュの生成
  - 停止可能な Web Worker での正規表現テスト
  - YAML と JSON の相互変換
- 韓国語、英語、日本語、簡体字中国語で、画面、各ツールページ、ガイドを利用できます。
- ツールの検索、お気に入り、最近使用したツールに対応しています。
- ライト、ダーク、システム設定に合わせたテーマを選べます。
- デスクトップとモバイルに対応した画面を提供します。
- 対応するツール間で、値を URL に含めずに入力を引き継げます。

## プライバシー

ツールへの入力はブラウザー内で処理され、ツールを開いている間はページのメモリー上に保持されます。アカウントシステムやアプリケーションサーバーはありません。ブラウザーのストレージには、テーマ、お気に入り、最近使用したツールなどの設定だけを保存します。
