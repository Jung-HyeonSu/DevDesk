## 13. Codex에 요구하는 최종 보고 형식

모든 구현과 검증을 수행한 후 `IMPLEMENTATION_REPORT.md`를 생성하고 대화에도 다음을 요약한다.

1. **완료 요약**: 주요 페이지/공통 기능/12개 도구/4개 언어.
2. **정적 아키텍처**: `output: 'export'`, `out/` 경로, 서버 의존성 없음 검증 결과.
3. **테스트**: 실행한 정확한 명령, 통과/실패 결과, 수정 내역.
4. **배포 방법**: `npm ci`, `npm run build`, Cloudflare Pages 출력 설정.
5. **SEO/광고 준비 상태**: sitemap/hreflang, 광고 비활성 기본값, 활성화 절차.
6. **운영자 설정 필요 사항**: 실제 도메인, 연락처, 광고 승인 ID, 필요 시 분석/동의 관리.
7. **Git 기록**: 기능별 커밋 목록, 원격 이름/브랜치, PHASE별 Push 수행 결과 및 최종 커밋 해시.
8. **미완료 사항**: 이유 및 후속 조치. 미완료 기능을 완료했다고 주장하지 않는다.
