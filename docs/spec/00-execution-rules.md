## 0. Codex 최상위 실행 지시

이 저장소에 **실제로 빌드·실행·검증 가능한 완성형 개발자 도구 플랫폼**을 구현한다. 기획서만 작성하거나 화면 목업만 만드는 것으로 끝내지 않는다. 이 문서는 요구사항과 구현 완료 조건의 기준이다.

1. 현재 저장소의 구조와 설정부터 확인한다. 기존 코드가 있다면 재사용하고, 없다면 프로젝트를 초기화한다. 기존 사용자의 파일이나 설정을 불필요하게 삭제하지 않는다.
2. 기술 스택은 **Next.js App Router + React + TypeScript + Tailwind CSS**를 기본으로 사용한다. Next.js 버전은 실제 설치 가능한 안정 버전을 선택하고, 공식 Static Export 지원 여부를 검증한다.
3. **절대적 제약: 배포 시 Node.js 서버, API 서버, DB, 서버리스 함수, Edge Function, Worker 서버, 유료 API가 없어야 한다.** 빌드할 때만 Node.js를 사용하고 배포 산출물은 오직 정적 HTML/CSS/JS/이미지/폰트 등이다. 브라우저의 Web Worker는 허용한다(서버가 아님).
4. 한국어(`ko`), 영어(`en`), 일본어(`ja`), **중국어 간체(`zh`, HTML `lang=zh-CN`)** 네 언어를 초기 릴리스부터 완전히 지원한다. 도구 UI뿐 아니라 SEO 제목, 설명, 사용법, 예제 설명, 오류 메시지, 정책 페이지까지 번역한다.
5. 핵심 도구 **12개를 실제로 구현**한다. 빈 페이지, 더미 버튼, 허위 성공 메시지, 핵심 기능 TODO를 출시 결과물에 남기지 않는다.
6. 모든 도구 입력의 처리·검증·변환은 브라우저 안에서만 수행한다. 입력 원문, JWT, SQL, 코드, 비밀번호 등을 자체 서버나 외부 변환 API로 보내지 않는다.
7. 프리미엄 개발자 도구 서비스처럼 디자인한다. 비슷한 기존 서비스를 그대로 복제하지 말고 브랜드와 레이아웃을 독자적으로 구성한다.
8. SEO, 접근성, 반응형, 오류 처리, 테스트, 문서, 광고 도입을 위한 안전한 구조까지 구현한다.
9. 구현 중 결정이 필요한 세부사항은 본 계획의 **비용 0원·정적 Export·4개 언어·정확성·유지보수성** 원칙에 맞춰 합리적으로 결정하여 진행한다. 사용자 확인을 기다리며 작업을 중단하지 않는다.
10. 개발을 마친 뒤 `lint`, `typecheck`, `test`, `build`, E2E/스모크 테스트를 실행하고, 실패한 항목은 수정 후 다시 검증한다. 실행할 수 없는 검증은 그 이유를 최종 보고서에 명시한다.
11. **Git 기능별 커밋과 단계별 원격 Push는 사용자가 명시적으로 요청한 작업이다.** 기존 저장소의 원격(remote)과 현재 브랜치를 확인하고 아래 15장의 규칙에 따라 실제 `git commit` 및 `git push`를 수행한다. 원격 저장소 생성·계정 연결·인증 우회·강제 Push는 수행하지 않는다. Git Push 이외의 도메인 구매, 광고 계정 승인, Cloudflare 계정 연결이나 설정 변경 등 외부 권한이 필요한 작업은 별도의 명시적 요청 없이 실행하지 않는다. Git Push가 기존 CI/CD를 통해 자동 배포를 유발할 수 있다는 점을 고려한다.
12. 최종 결과는 **변경 파일, 구현 도구, 4개 언어 지원 현황, 테스트 결과, 기능별 커밋 내역 및 Push 결과, 로컬 실행 명령, 정적 배포 절차, 남은 외부 설정 항목**으로 보고한다.

### Non-negotiable (절대 변경 금지)

- [ ] `next.config.ts`에 `output: 'export'`가 활성화되어 있다.
- [ ] `npm run build`만으로 `out/` 정적 산출물이 생성된다.
- [ ] Cloudflare Pages 무료 플랜에 `out/`만 업로드해 동작한다.
- [ ] 프론트엔드가 호출하는 자체 API, `app/api`, 서버 요청별 SSR, Server Actions, 자체 인증/회원가입, DB가 없다.
- [ ] Vercel Functions, Cloudflare Workers/Pages Functions, Supabase, Firebase 인증·DB, 유료 SaaS가 핵심 기능에 필요하지 않다.
- [ ] 모든 12개 도구와 핵심 페이지가 4개 언어 경로에서 실제로 작동한다.
- [ ] 환경변수가 없더라도 핵심 도구가 실행된다. 광고·분석 기능은 설정 전 비활성화한다.
