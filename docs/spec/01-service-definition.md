# 상세 요구사항 01 — 서비스 정의

> 기존 GOAL.md의 §1를 분리한 문서입니다. 요구사항 본문은 원문을 유지합니다.

## 1. 서비스 정의

| 항목 | 결정 |
|---|---|
| 가칭 | **DevDesk** (배포 전 이름/상표/도메인 중복 확인; 코드 내 쉽게 교체 가능한 설정값) |
| 제품 | 무료 브라우저 기반 개발자 유틸리티 모음 |
| 사용자 | 프론트엔드·백엔드·DevOps 개발자, 데이터/QA 엔지니어, 기술 학습자 |
| 핵심 가치 | 빠르고, 사용하기 쉽고, 브라우저에서 처리하여 입력 데이터가 외부 변환 서버로 전송되지 않는 도구 |
| 수익 모델 | 광고 승인 후 Google AdSense; 초기에는 광고 코드·슬롯만 준비 |
| 저장소 | 코드 Git 저장소 1개, 빌드 산출물 `out/` |
| 배포 | **Cloudflare Pages의 정적 사이트** 무료 플랜 우선 |
| 회원가입 | 없음 |
| DB | 없음 |
| 운영 목표 | 유료 서버·서버리스 호출·유료 AI API로 인한 운영비 0원 구조 |

> 비용 안내: 무료 플랜에는 사용량/빌드/파일 수 제한이 있으며 정책이 변동할 수 있다. 별도 도메인 구매는 비용이 들 수 있으므로 필수가 아니다. `*.pages.dev` 주소로 무료 시작할 수 있게 한다. 광고 수익 및 검색 순위는 보장하지 않는다.

### 사용자 핵심 시나리오

1. 구글에서 'JSON formatter' 검색 → `/en/tools/json-formatter/` 진입 → 입력 후 즉시 정렬/복사 → 관련 도구로 이동.
2. 한국 개발자 → `/ko/tools/sql-formatter/`에서 Oracle/MariaDB SQL 정렬 → 실행 서버 연결 없이 복사.
3. 일본 사용자 → 일본어 검색 유입 → 일본어 설명·에러·버튼·SEO가 있는 동일 도구 사용.
4. 중국어 간체 사용자 → `/zh/tools/jwt-decoder/`에서 JWT 내용을 디코딩 → 서명 미검증 경고 확인.
5. 재방문 사용자 → `Ctrl/Cmd + K`로 도구 검색 → 즐겨찾기로 빠른 작업.
