## 14. 기술 근거 및 공식 문서

구현 시 해당 시점의 공식 문서를 기준으로 세부 API/설정을 검증한다.

- Next.js Static Exports: https://nextjs.org/docs/app/guides/static-exports
- Next.js generateStaticParams: https://nextjs.org/docs/app/api-reference/functions/generate-static-params
- Cloudflare Pages — Next.js static site: https://developers.cloudflare.com/pages/framework-guides/nextjs/deploy-a-static-nextjs-site/
- Cloudflare Pages Free 한도: https://developers.cloudflare.com/pages/platform/limits/
- Google Search — localized versions / hreflang: https://developers.google.com/search/docs/specialty/international/localized-versions
- Google AdSense — 사이트 준비: https://support.google.com/adsense/answer/7299563
- Google AdSense — 프로그램 정책: https://support.google.com/adsense/answer/48182

**최종 원칙:** 무료 정적 호스팅, 브라우저 자체 처리, 4개 언어, 실제 동작하는 도구, 검색 유입 가능한 콘텐츠, 광고 승인을 위한 품질을 동시에 만족하는 제품을 완성한다.
