## 6. SEO 및 검색 유입 전략

### 6.1 페이지별 필수 콘텐츠

도구 상세 페이지에는 **정적 HTML로 렌더링되는 실제 유용한 콘텐츠**를 넣는다.

1. 현지화된 H1과 1~2문장 가치 설명.
2. 즉시 사용할 수 있는 도구 UI.
3. 실제 입력·출력 예시 2개 이상.
4. 사용 방법 3~5단계.
5. 도구 특화 주의사항 및 오류 해결 설명.
6. 질문과 답변 3개 이상(도구별로 의미 있게 작성; 복붙 FAQ 금지).
7. 관련 도구 3~5개 내부 링크.

- 각 도구의 콘텐츠는 JSON/JWT/Cron/SQL 등의 실제 의미를 설명해야 하며 단순 키워드 반복 금지.
- `title`/`description`은 언어와 도구마다 고유하게 작성.
- 중복 영문 설명을 4개 경로에 그대로 넣지 않는다.
- `SoftwareApplication`/Breadcrumb 구조화 데이터는 실제 표시 내용과 일치하는 경우에만 활용.
- `sitemap.xml`, `robots.txt`, canonical, hreflang은 빌드 결과물로 실제 제공.
- GA4/Search Console 연결은 운영자가 설정할 때까지 선택사항이며 핵심 기능과 분리.
- 검색엔진이 JS 실행 없이도 페이지의 도구명, 설명, 사용법, 링크를 볼 수 있게 한다.

### 6.2 언어별 콘텐츠 품질

- 한국어: 실무 친화적 문장, 약어는 영문 원어 병기.
- 영어: 자연스러운 개발자 문서 문체.
- 일본어: 자연스러운 일본어 UI·기술 용어·문장 부호.
- 중국어: 간체 중국어 및 해당 지역에서 통용되는 기술 용어.
- 번역 문구가 어색한 경우 의역 가능하되 기능/보안 의미를 훼손하지 않는다.

### 6.3 SEO 기계적 검증

- 12개 도구 × 4개 언어 = **48개 실제 정적 상세 도구 페이지** 생성.
- 각 도구 페이지의 canonical과 다른 3개 언어 alternate 링크 검증.
- `hreflang`의 `zh-CN` 표기, 루트 `x-default` 검증.
- 존재하지 않는 도구·언어를 sitemap에 넣지 않음.
- 빌드 산출물 HTML에서 H1, title, meta description, lang, 가이드 본문 추출해 자동 점검.
